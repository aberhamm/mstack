## Requirements

`skills/mstack-run/SKILL.md` Step 7a ("### 7a. On success", lines 786-1075,
~290 lines) narrates a FIXED linear sequence of gate assertions and git
commands in prose — the audit's context-budget finding, and prose-narrated
determinism is exactly the pattern this repo keeps converting to scripts
(`result-gate.sh`, `review-gate.sh` precedents). The "Full linear order"

## Design

`complete.sh <plan-path> --result <result-block-file> --notes <notes-file>
--message <commit-msg-file>` (exact interface decided at implementation;
inputs are files, not args, to survive quoting). It sources `lib.sh`, calls
the existing gate scripts rather than reimplementing them, and prints one
machine line per stage so the skill can report progress. Abort paths that
write plan frontmatter (blocked + `needs-review:` from assert-completable
stderr; failed + `failed-reason`) move into the script too — they are
deterministic edits with fixed commit messages (`chore(plan NNN): blocked,
review gate open`).

Smoke: a new `complete-smoke.sh` rather than extending `hook-chain-smoke.sh`
— the hook suite tests the write-layer hook, this tests the honest path;
mixing them muddies the layer model. Fixture repo pattern copied from
`review-gate-smoke.sh` (temp git repo, fixture plan, stub result blocks).
Register the suite in AGENTS.md's smoke list, the pre-commit hook source
(`skills/mstack-run/hooks/pre-commit:62` suite loop), and the `.githooks/`
copy (edit the source, `cp` to `.githooks/` — never `./setup` from
`~/dev/mstack`).

Blocked-by rationale: 069/070 touch Step 7a's text/semantics directly (069's
in-progress→done status fix in particular changes the status-write line this
script hard-codes); 063/067 add smoke suites to the SAME pre-commit

after them avoids re-doing the loop registration. Extracting before any of
the four would force that work to be re-done inside `complete.sh` or the

Known open follow-up, noted but NOT changed: some pre-fix tags are
lightweight and `--follow-tags` doesn't push them (the tag-stranding story,
SKILL.md:1026-1037 and 1061-1074). Keep current behavior.
